# EGC5310 – Estruturas de Dados

Projeto pedagógico da disciplina **EGC5310 – Tópicos Especiais em Ciência de Dados VI**, ofertada no curso de Ciência de Dados da UFSC.

**Professor:** Vinicius Ramos  
**Oferta inicial:** 2026/2

## Objetivo

Este repositório reúne os materiais da edição da EGC5310 dedicada a **Estruturas de Dados e Algoritmos para Manipulação de Dados**.

A disciplina é organizada semanalmente. Cada semana parte de um problema concreto e integra discussão, implementação, experimentação e análise de desempenho.

## Estrutura

- `Documentos-Base/` — documentos permanentes da disciplina.
- `PlanoEnsino/` — Plano de Ensino da oferta vigente.
- `Semana01/`, `Semana02/`, ... — materiais semanais.
- `assets/` — recursos compartilhados.

## Estrutura semanal

Cada semana poderá conter:

1. Roteiro
2. Slides
3. Notebook Aula
4. Notebook Estudante
5. Benchmark
6. Exercícios
7. Soluções
8. Revisão

## Ambiente computacional

Os notebooks são preparados prioritariamente para Google Colab.

O AVA é utilizado para comunicação oficial e disponibilização dos links.

O GitHub funciona como repositório versionado do projeto pedagógico.
